# reorder-repositories command

Read the complete `repositories` array and assess recent commits, branch synchronization, uncommitted changes, and recent-use records. Put frequently or recently active repositories first with `ui.collapseToMore: false`, and long-inactive repositories later with `ui.collapseToMore: true`. Keep the total number of non-collapsed repositories preferably below 10; when there are more, keep only the most active repositories non-collapsed and place the rest in More. When activity is unknown, preserve relative order and existing values. Produce a preview with evidence, proposed positions, and collapse values, then wait for explicit confirmation. After confirmation, change only repository order and `ui.collapseToMore`, validate the complete document, and never write without confirmation or after validation failure.
